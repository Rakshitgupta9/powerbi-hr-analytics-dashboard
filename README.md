# 👥 HR Analytics Dashboard (Power BI)

## 🔍 Overview
This project presents an interactive **HR Analytics Dashboard** built using Power BI to analyze employee attrition, workforce demographics, compensation, satisfaction metrics, and organizational trends.

The dashboard helps identify workforce attrition patterns and supports data-driven HR decision-making through interactive visual analysis.

This project demonstrates **data cleaning, duplicate removal, preprocessing, DAX calculations, KPI design, drill-down analysis, and dashboard storytelling using Power BI**.

---

## 📈 Key Metrics
- **Total Employees:** 1,470
- **Average Age:** 36.92
- **Attrition Count:** 237
- **Attrition Rate:** 16.12%
- **Average Years at Company:** 7.01
- **Average Salary:** 6.50K

---

## 🧹 Data Cleaning & Preparation
Performed preprocessing on raw HR data before dashboard development:

- Removed duplicate employee records to improve data accuracy
- Cleaned and validated workforce dataset
- Standardized categorical values for consistent analysis
- Processed CSV data using Power Query
- Structured data for KPI calculations and dashboard reporting

---

## 📊 Dashboard Features

### 🔹 Workforce Overview
- Total employee count
- Average employee age
- Average salary
- Average years at company
- Overall attrition count and attrition rate

### 🔹 Attrition Analysis
- Employee attrition by age group
- Attrition by marital status
- Attrition by salary slab
- Attrition trends by years at company
- Attrition comparison by overtime
- Attrition distribution by gender

### 🔹 Employee Satisfaction Analysis
- Job satisfaction score
- Work-life balance score
- Interactive drill-down analysis

### 🔹 Workforce Segmentation
- Department-wise filtering using slicers
- Job role and education field attrition matrix
- Gender distribution analysis
- Salary-based attrition segmentation

## 🧠 Key Insights
- Employees aged **26–35** show the highest attrition levels.
- Single employees have the highest attrition compared to married and divorced employees.
- Employees in lower salary brackets contribute significantly more to attrition.
- Certain job roles experience disproportionately higher attrition rates.
- Moderate job satisfaction and work-life balance may indicate employee retention concerns.

## 📌 Business Use Case
This dashboard can help HR teams and business leaders:

- Monitor employee attrition trends
- Identify high-risk workforce segments
- Understand potential attrition drivers
